# Imperfecto vs. Indefinido

Sitio web interactivo listo para GitHub Pages.

## Publicar
1. Sube `index.html` y la carpeta `assets/` a un repositorio.
2. Activa GitHub Pages desde la rama principal y la carpeta raíz.
3. No cambies la ruta `assets/audio_latino.mp3` salvo que actualices también el HTML.

## Incluye
- Traducción al inglés al pasar el cursor.
- Gramática visual en diapositivas.
- Contraste “fotografía vs. película”.
- Audio original y comprensión V/F.
- Tarjetas de conversación.
- Escritura guiada y teclado de tildes/ñ.
- Quiz automático.
- Guardado local, exportación/importación de progreso.
- Zoom de toda la interfaz y pantalla completa.
